# glyphtrail-viz

Glyphtrail visualization: a self-contained interactive code-graph HTML page.

A crate of [**glyphtrail**](https://glyphtrail.dev) — map codebases as semantic and
historical graphs: query structure, trace lineage, and discover recurring ideas
across time. See the [project README](https://github.com/glyphtrail/glyphtrail#readme).
